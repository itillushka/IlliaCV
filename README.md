# Illia Pastushok - CV Portfolio

Personal portfolio website showcasing my experience as a Machine Learning Engineer & AI Tech Lead.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- tsparticles (animated background)
- Lucide React (icons)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Features

- Animated particle background
- Scroll-triggered section animations
- Interactive server room hero effect
- Downloadable PDF CV
- Responsive dark theme design

## Live Sections

1. Hero - Introduction with key stats
2. Profile - About me
3. Skills - Technical expertise (6 categories)
4. Experience - Work history
5. Projects - Featured work
6. Education - Academic background
7. Certifications - Professional credentials
8. Languages - Language proficiency
9. Additional - Extra information
10. Footer - Contact & social links
